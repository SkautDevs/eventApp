## The browser test case

`tests/Browser/BrowserTestCase` starts its own PHP built-in server (`bin/router.php`, `PROGRAM_PROVIDER_<SLUG>=local` pinned for every event in `EventCatalog::slugs()` so a dev `.env` pointing one at kissj never reaches a real API, `PUSH_DB_PATH=var/browser-test.sqlite`, and `SESSION_PATH` and `STUB_STATE_PATH` at 0700 temp dirs of the class's own, removed afterwards, so a run leaves no root-owned `var/sessions` or `var/stub`) and drives either a local chromedriver (`PANTHER_CHROME_DRIVER_BINARY` or PATH; CI) or Selenium (`PANTHER_SELENIUM_URL`, with `BROWSER_TEST_HOST`; the compose `test` service). Every test runs at a 412 × 915 phone, but headless Chrome clamps its window to at least 500px, so `--window-size` (`windowSize()`) is not enough: the class overrides the device metrics over CDP (`Emulation.setDeviceMetricsOverride`, the protected `overrideViewport()`, which a test that narrows the page puts back) and passes `--hide-scrollbars`, so `clientWidth` is the viewport's. The lane is **hermetic**: `--host-resolver-rules=MAP * ~NOTFOUND, EXCLUDE <test host>` makes every third-party host (the Maps iframe, Chrome's own Google traffic) fail at once, because one request that hangs after it was sent holds the load event, Chrome has no timeout for that, and the WebDriver navigate then dies on php-webdriver's 180 s curl timeout — the intermittent first-page stall the lane used to have. Fonts and icons are self-hosted, so the screens render with their real typefaces and icons there; only the map's iframe is missing. `bin/baseline.php` subclasses it (its `mode()`, `localClient()`, `remoteClient()` and `removeDatabase()` are protected for that) and so shoots the baseline under the same rule, in the real look.

## The functional test case

`tests/Functional/AppTestCase::createApp()` boots the real app against event fixtures — either a real event under `events/<slug>/` or a minimal fixture event under `tests/fixtures/events/` (among them `window-before` and `window-open`, whose registration windows lie far in the future or around now, so no assertion depends on a real event's dates) — and returns the real Slim `App`/response. It gives every app an in-memory migrated database (`AppTestCase::memoryDb()`, passed as `\PDO::class`), null loggers, a `SpyPushSender` and a fresh `STUB_STATE_PATH` per test; a test that wants to look inside passes its own (`CountingProgramProvider`, `DelegatingProvider` and `ThrowingProgramProvider` wrap or replace the provider). No test hits a live external API; everything program-related comes from the `local` provider's JSON fixtures.
