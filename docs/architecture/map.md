# Map

This document covers Místa: the Google map, the self-hosted site plan, and how the two share one screen.

## Místa

`MapModule` (`/mapa`; the tab, the app bar title, the document title and the screen's label all read **Místa**, while the view pill inside keeps `Mapa` and `Plán`) reads `map.embedUrl` (a Google My Maps embed; a `REPLACE-ME` placeholder counts as none; obrok27's is the 2027 map, `…/maps/d/embed?mid=1KLPkQqPYxomrNmxTc0FfPZ44P5AxLRg`, which renders only if it is shared publicly in My Maps), `map.image` (a path under `www/`, the handbook's own site plan, self-hosted so it works offline and shown as an `<img>`, so an SVG is drawn and never run) and the optional `map.imageAlt` (default `Plán areálu`), and `map.twig` has three branches: the embed alone renders exactly the markup it always did (`<div class="map" data-map>` with its iframe as a lone child, then the offline note); the plan alone is a `.mapview[data-map-root]` with one plan pane and no switcher; both make `<div class="mapview" data-map-root data-map-event="<slug>" data-view="google" data-morph-keep="data-view">` holding two `role="tabpanel"` panes (`#map-view-google`, `#map-view-plan`) and the Program screen's floating pill — the same `.tabs-wrap`/`.tabs`/`.tabs-indicator`/`.tabs-tab` markup and CSS, `aria-label="Zobrazení mapy"`, `Mapa` and `Plán`, `--tabs-height` being declared on `:root` already. A hidden pane is `display: none`, never detached, so Google's iframe keeps running behind the plan. The behaviour is `www/map.js`, loaded by the layout for an event with the `map` feature: one idempotent `window.mapInit(scope)`, wired on `DOMContentLoaded` and `screen:shown` like `pgInit`, that keeps the reader's view in `sessionStorage['mapView:<slug>']` and the plan's zoom in `sessionStorage['planZoom:<slug>']` (written after a button step and once when a pinch ends, never on each `pointermove`), opens on Plán whenever `navigator.onLine` is false (offline, Google's map is a blank box), walks the tabs with the arrow keys, and re-asserts the view's `aria-selected`/`tabindex` on `screen:morphed`, since `data-view` is the only state the morph keeps for it. The plan zooms by its **width** (`img.style.width` at 100–600 %, steps of ×1.4, the first width set without the scroll maths), never a transform, inside a `.plan` box that scrolls both ways with the browser's own panning (`touch-action: pan-x pan-y`); the −/+ pair (`.plan-zoom-btn`, 44 × 44, in `ThemingTest`'s px allowlist beside `.pager-zoom-btn`) anchors on the box's centre and a two-finger pinch on the midpoint between the fingers, each recomputing `scrollLeft`/`scrollTop` so that point stays put, and a button disables at its end of the range. obrok19 carries a stand-in plan (`www/events/obrok19/plan-example.png`, the CEJ 2022 site map, `Ukázkový plán areálu`) for the reference event and the browser tests; obrok27's is `plan-josefov.png` (`Plán areálu pevnosti Josefov`), drawn in the CEJ plan's style from the participant-facing part of its My Maps layer (north up, portrait); navigamus27's is `plan-navigamus-n27.png` (`Plán areálu Navigamus`), drawn the same way from its own layer but framed in the 2027 identity (Seatren title, Luciao labels, red boundary, N27 badge) (`…/maps/d/embed?mid=10NCIWeMWKOuIGCR9SmckCIazhgMZx5Y`, north up, landscape).
