# Map

This document covers Místa: the Google map, the self-hosted site plan, how the two share one screen, and the note that stands in for the map offline.

## Místa

`MapModule` (`/mapa`; the tab, the app bar title, the document title and the screen's label all read **Místa**, while the view pill inside keeps `Mapa` and `Plán`) reads `map.embedUrl` (a Google My Maps embed; a `REPLACE-ME` placeholder counts as none; obrok27's is the 2027 map, `…/maps/d/embed?mid=1KLPkQqPYxomrNmxTc0FfPZ44P5AxLRg`, which renders only if it is shared publicly in My Maps), `map.image` (a path under `www/`, the handbook's own site plan, self-hosted so it works offline and shown as an `<img>`, so an SVG is drawn and never run) and the optional `map.imageAlt` (default `Plán areálu`), and `map.twig` has three branches: the embed alone renders exactly the markup it always did (`<div class="map" data-map>` with its iframe as a lone child, then the offline note); the plan alone is a `.mapview[data-map-root]` with one plan pane and no switcher; both make `<div class="mapview" data-map-root data-map-event="<slug>" data-view="google" data-morph-keep="data-view">` holding two `role="tabpanel"` panes (`#map-view-google`, `#map-view-plan`) and the Program screen's floating pill — the same `.tabs-wrap`/`.tabs`/`.tabs-indicator`/`.tabs-tab` markup and CSS, `aria-label="Zobrazení mapy"`, `Mapa` and `Plán`, `--tabs-height` being declared on `:root` already. A hidden pane is `display: none`, never detached, so Google's iframe keeps running behind the plan. The behaviour is `www/js/map/`, whose entry the layout loads for an event with the `map` feature. `map/index.js` wires each `[data-map-root]` once (marked `data-map-ready="1"`): the document's own screen when the module evaluates, and a screen the loader inserts on `screen:shown`. `map/views.js` (`setupViews()`) keeps the reader's view in `sessionStorage['mapView:<slug>']` and the plan's zoom in `sessionStorage['planZoom:<slug>']` (written after a button step and once when a pinch ends, never on each `pointermove`), opens on Plán whenever `navigator.onLine` is false (offline, Google's map is a blank box), walks the tabs with the arrow keys, and re-asserts the view's `aria-selected`/`tabindex` on `screen:morphed`, since `data-view` is the only state the morph keeps for it. `map/plan.js` (`setupPlan()`) zooms the plan. It zooms by its **width** (`img.style.width` at 100–600 %, steps of ×1.4, the first width set without the scroll maths), never a transform, inside a `.plan` box that scrolls both ways with the browser's own panning (`touch-action: pan-x pan-y`); the −/+ pair (`.plan-zoom-btn`, 44 × 44, in `ThemingTest`'s px allowlist beside `.pager-zoom-btn`) anchors on the box's centre and a two-finger pinch on the midpoint between the fingers, each recomputing `scrollLeft`/`scrollTop` so that point stays put, and a button disables at its end of the range. obrok19 carries a stand-in plan (`www/events/obrok19/plan-example.png`, the CEJ 2022 site map, `Ukázkový plán areálu`) for the reference event and the browser tests; obrok27's is `plan-josefov.png` (`Plán areálu pevnosti Josefov`), drawn in the CEJ plan's style from the participant-facing part of its My Maps layer (north up, portrait); navigamus27's is `plan-navigamus-n27.png` (`Plán areálu Navigamus`), drawn the same way from its own layer but framed in the 2027 identity (Seatren title, Luciao labels, red boundary, N27 badge) (`…/maps/d/embed?mid=10NCIWeMWKOuIGCR9SmckCIazhgMZx5Y`, north up, landscape).

## Offline

Google's iframe is a blank box without a network, so `map.twig` puts a `<p class="empty map-offline" data-map-offline hidden>Mapa potřebuje připojení.</p>` right after the `[data-map]` box. On a two-view Místa the note is `.empty.map-offline.map-offline-plan`: its sentence is wrapped in `<span class="map-offline-text">` and followed by a `Zobrazit plán` button (`data-map-view="plan"`, which `map/views.js` handles). That note stays opaque and only the sentence takes `.empty`'s 0.8 fade, because the tonal `.btn` under it falls below AA at that opacity on a light set. `map/offline.js` only toggles the note's `hidden` and never rewrites it. It finds the map as the note's `previousElementSibling`, so nothing may come between them. On `DOMContentLoaded`, `screen:shown`, `screen:morphed`, `online` and `offline` it hides a map that never loaded behind the note while `navigator.onLine` is false, and reloads its iframe once the signal is back. A map that did load stays as it is, with no note: one capture-phase `load` listener marks it `data-map-loaded` while online. `map/index.js` imports `offline.js` first, so the note's listeners run before the views'.
